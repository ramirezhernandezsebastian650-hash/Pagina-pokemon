# PokéDex Manager - Gestor de Pokémon

¡Bienvenido a **PokéDex Manager**! Una aplicación web interactiva y ligera diseñada para gestionar, agregar, editar y visualizar tarjetas de Pokémon con sus respectivas estadísticas e imágenes.

## Características

- **Agregar nuevos Pokémon:** Ingresa nombre, tipo, estadísticas (HP, Ataque, Defensa) y la URL de una imagen.
- **Editar Pokémon existentes:** Modifica los atributos o imágenes de cualquier Pokémon en tiempo real.
- **Eliminar Pokémon:** Remueve tarjetas de la lista dinámica.
- **Diseño Responsive:** Interfaz adaptable a pantallas de escritorio, tablets y dispositivos móviles.
- **Estilo Limpio y Moderno:** Tarjetas elegantes con paleta de colores inspirada en la franquicia Pokémon.

---

## Tecnologías Utilizadas

- **HTML5:** Estructura semántica del documento (`index.html`).
- **CSS3:** Hojas de estilo personalizadas (`styles.css`) con variables CSS, Grid Layout, Flexbox y transiciones.
- **JavaScript (ES6+):** Lógica dinámica (`script.js`) para manipulación del DOM y gestión del estado en memoria.
